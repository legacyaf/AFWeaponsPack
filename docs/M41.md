# AF M41 Pathfinder

WW2-style bolt-action sniper rifle. Second weapon of the pack, and the first one built by following `docs/PIPELINE.md`.

| | |
|---|---|
| Classes | `AFM41_Pathfinder` (walnut), `AFM41_Pathfinder_Gold` (gold floral on black furniture) |
| Pack version | 0.8.0 |
| Size | LOD 1: 6,957 triangles; LODs 2-4: 5,216 / 3,478 / 2,503; 4096 px textures |
| Inherits | vanilla `Mosin9130` (animations, sounds, recoil, internal 5-round magazine) |
| Ammunition | 7.62x54mmR, loose rounds or the Mosin stripper clip |
| Attachments | PU scope, Mosin compensator, improvised suppressor, Mosin bayonet |
| Model | `source/AF_Weapons/afm41_pathfinder/afm41_pathfinder.p3d` |
| Blender | `blender/afm41_pathfinder_detailed.py`, `_dayz_export.py`, `_run.py` |

## Look

Full-length walnut stock with a straight wrist and finger grooves, upper handguard, blued barrel and fittings, bright bolt with a turned-down handle, tangent rear sight, eared front sight, cleaning rod, bayonet lug, steel butt plate. A dark steel disc with the orange AF logo is let into both sides of the butt.

## Frame and numbers taken from the vanilla Mosin

The model is built in the Mosin's own frame (see `docs/PIPELINE.md`, step 3).

| Vanilla feature | Working-frame value |
|---|---|
| Bore line | z = 0.1161 |
| Muzzle / butt | y = 0.8305 / y = -0.409 |
| Bolt axis | z = 0.1147 |
| Bolt handle station | y = 0.013 |
| Trigger pivot | y = -0.0515, z = 0.0676 |
| Iron-sight eye point | y = -0.1582, z = 0.1377 |
| PU scope proxy | y = 0.0094, z = 0.1245 |

## Bones

The Mosin skeleton has nine bones. The model uses four:

| Bone | Part | Certainty |
|---|---|---|
| `trigger` | trigger | name is unambiguous |
| `bolthandle` | handle and knob | name is unambiguous |
| `boltbody` | bolt | name is unambiguous |
| `boltbodys` | cocking piece | **inferred**: assumed to be the part of the bolt that slides without turning |

`magazine`, `bullet`, `bullet1`, `rotation_a`, `rotation_b` belong to the loading clip and its rounds on the vanilla rifle; the model has nothing in them.

## Status

Built, binarized and signed. Checked outside the game: `config.cpp` compiles, Object Builder's script engine loads all nine LODs with the right selections, 4 kg mass and convex collision, the binarized model carries the same nine-bone skeleton as the vanilla Mosin, and the signature verifies.

**Not yet tested in game.** The checklist is in `docs/TESTING.md` (steps M1-M7). First things to check, in order:

1. Bolt cycle: handle lifts and the bolt slides back as one piece. If the cocking piece stays behind or moves oddly, `boltbodys` is the wrong bone for it; move that part to `boltbody` in `afm41_pathfinder_dayz_export.py`.
2. Hand positions on the stock and bolt knob.
3. Iron sight picture: front blade centred in the rear notch.
4. PU scope seating on the receiver.
5. Compensator, suppressor and bayonet positions at the muzzle.
6. Wood colour and shine in daylight.

## Not done yet

- Stripper clip and rounds are not shown during loading (the vanilla rifle shows them through the `magazine` / `bullet` bones).
- No ghillie wrap slot.
- The gold finish has only been previewed in Blender, where the steel reads grey; in game it should be black, as on the AF-7 Gold.
- Sling is not modelled.
- Handguard and stock are simple rounded sections; no checkering, stamps or serial numbers.
